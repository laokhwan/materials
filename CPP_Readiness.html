Common Mistakes

  • = vs ==
  • index คือ 0..n-1
  • int / int ตัดทศนิยม
  • ข้อมูลติดลบ: อย่าเริ่ม max = 0
  • vector a(n) มี n ตัวแล้ว
  • find ต้องตรวจ end() ก่อน
